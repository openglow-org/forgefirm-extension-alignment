# Visual alignment for ForgeFIRM

`org.openglow.alignment`, an official ForgeFIRM extension package: the head
camera's view with a crosshair and a jog pad beside it, and one button that
moves the beam to where the crosshair was, for LightBurn's Start From:
Current Position.

It is also an example of a package's repository at its smallest: a page and
nothing that runs on the machine, a `make stage` that lays out what it
ships, and forgeext's shared workflow, which lints and packs it on every
push and signs and publishes each new version as a release.
